# Como correr este proyecto?

Antes de ejecutar este proyecto, se tiene que descargar el instaldor de paquetes UV de Python, disponible en: https://docs.astral.sh/uv/. Obviamente también se necesita tener python instalado en el dispositivo

Para la tarea 1 se hacía con Docker. Hize un montón de cambios y mejor no. La prueba del hw1 quedó en el google forms de la entrega respectiva ya que me cambié de equipo de trabajo.

Para la tarea 2, simplemente implemente ingresar a ./hw2/backend/ y escribir los siguientes dos comandos:

`uv sync`
`uv run python manage.py runserver 0.0.0.0:8000`
